# Sistema de Loja em Python

Sistema de terminal para calcular desconto e troco em uma loja.

## Funcionalidades
- Cálculo de desconto percentual sobre o preço do produto
- Cálculo de troco (valor pago - valor do produto)
- Tratamento de erros de entrada (validação de dados numéricos)
- Menu interativo em loop

## Tecnologias
- Python 3.14

## Como executar
```bash
python loja.py
```
